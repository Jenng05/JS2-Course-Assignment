# JS2 Course Assignment

A social media application built with vanilla JavaScript and the Noroff API.

## Features

- Register and login
- View all posts in a feed
- Create, edit and delete your own posts
- View single posts
- View user profiles
- Follow/unfollow users
- Search posts

## How to run the project

1. Clone the repository
2. Open with Live Server in VS Code
3. Or visit the live site below
